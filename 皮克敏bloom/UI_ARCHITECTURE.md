## 2. 主页布局与会话状态

```
[Lv]  [设置]
Strawberry / SEEDLING
(对话气泡)

     ┌ 太阳徽章 · 剩余 12:40  → 点击打开同步页
     │   3D 植物（可旋转缩放）
     │   + 右上小太阳旋转（会话进行时）
     └ 浇水时：水壶序列帧在花盆上方倾倒

[今日 2/3 · +12 光合 · 进度环]
[ ☀ 晒太阳 ] [ 💧 喝水 ] [ 🚶 散步 ]   ← 快捷动作条（插画icon，禁emoji）
[图鉴] [同步] [日记]                    ← Tab
        (拍照 FAB)
```

**快捷动作条状态机（支持多会话并发）：**

| 卡片状态 | 表现 | 点击行为 |
|---|---|---|
| 未开始 | 白底常态 | 晒太阳/散步 → 立即开始会话并展开会话卡；喝水 → 立即记一杯 |
| 进行中 | 橙色高亮 + 实时计时文字（「进行中 05:32」） | 打开该会话卡片（含结束按钮）；不中断会话 |
| 今日已上限 | 灰态 + 「已达标」 | 打开同步页查看记录 |

多个会话同时进行时，各卡片独立高亮计时；点某张卡只操作该会话。会话卡片从底部弹出，一次只显示一个会话详情，其余会话在卡片顶部以小字显示「另有散步进行中 04:10」。

### 3.3 提醒设置

**列表结构：** 每条 = `[icon] 话术 · 时刻 · 重复标签 · 来源标签(植物/自定) · [开关] [编辑] [删除]`
植物主动条目带条件触发标识（「仅晴天 / 仅当未喝水」），不可删除，可关闭与改时间。

| 来源 | 时间 | 条件 | 话术 | 开关 |
|---|---|---|---|---|
| 植物 | 08:30 | 天气晴 | 今天去窗边吗？我想晒太阳 | 默认开 |
| 植物 | 10:30 | 今晨无饮水 | 你喝水了吗？我也口渴 | 默认开 |
| 植物 | 13:00 | — | 饭后走走，风会穿过叶子 | 默认开 |
| 植物 | 16:00 | 检测到久坐 | 起来动一动，我也想伸懒腰 | 默认开 |
| 植物 | 19:30 | 今日拍照<3 | 再拍一张今天的自然 | 默认开 |
| 植物 | 21:30 | — | 早点睡，明天一起晒太阳 | 默认开 |
| 自定 | 用户设 | 用户设 | 自定义文案（默认植物口吻） | 用户 |

**添加/编辑表单：** 类型（晒太阳/喝水/散步/拍照/休息早睡）· 时刻 · 提前量 0/10/30min · 重复（每天/工作日/自定义星期几）· 文案。

**防打扰：** 单日植物主动提醒 ≤4 条；静音时段 22:00–08:00；「让植物安静一天」按钮。

**演示模式：** 「模拟 10:30 到点」按钮，直接触发完整通知流（气泡 + 提示音 + CTA），便于评审。

**通知交互：** 点击通知 → 深链直达对应动作（晒太阳计时 / 记一杯 / 相机 / 早睡打卡）。

## 4. 动效规格（同步反馈）

**实现分层：**
- HUD 层（2D 序列帧精灵）：太阳徽章——固定屏幕右上角，不进 3D 场景
- 前景叠加层（2D 序列帧 + 屏幕投影锚定）：水壶倾倒——每帧把花盆土面 `worldPos.project(camera)` 投影为屏幕坐标作锚点，保证旋转/缩放 3D 时水壶始终对准花盆
- 3D 场景内（程序化）：水滴粒子（THREE.Points 抛物线）、土面湿润（材质 color lerp）、植株高光（emissive 扫过）、叶摆（骨骼/顶点正弦）

| 事件 | 位置 | 表现 | 技术 | 时长 |
|---|---|---|---|---|
| 晒太阳进行中 | 右上角 | 8 帧太阳精灵旋转发光 + 外圈进度弧 + mm:ss | 2D 序列帧（S-01/S-02） | 与人曝晒时长 1:1 |
| 晒太阳结束 | 植株 | emissive 高光扫过 + 「+N 光合」+ 叮声 | 3D 程序化 + F-02 | 1.2s |
| 喝水 | 花盆上方 | 12 帧水壶倾倒，水滴粒子抛物线落土，土面加深后 2s 恢复 | 2D 帧（S-03）锚定 + 3D 粒子/材质 + F-01 | 0.8s |
| 散步（进行/结束） | 叶片 | z 向微摆 + 气流线（S-07） | 3D 骨骼/顶点 + 2D 叠加 | 进行中常驻轻摆 |
| 深呼吸 | 植株 | 随引导节奏缩放舒展 | 3D 程序化 | 跟随引导 |
| 施肥 | 土面 | 营养颗粒撒落 | 2D 帧 + 3D 粒子 | 0.8s |
| 提醒到 | 全屏轻提示 | 植物气泡 + 提示音（F-03）+ CTA | 系统通知/应用内 | 可稍后 |

## 5. 状态与数据

```ts
type Session = { id:string; kind:'sun'|'walk'|'breathe'|'stretch'|'air'|'sunflower';
  startTs:number; endTs?:number; minutes?:number; steps?:number; source:'auto'|'manual' };
type InstantEvent = { id:string; kind:'water'|'fruit'|'talk'; ts:number; ml?:number;
  source:'manual'|'health'|'bottle' };
type Reminder = {
  id: string;
  kind: 'sun'|'water'|'walk'|'photo'|'rest';
  source: 'plant'|'user';
  hh: number; mm: number;
  advanceMin: 0|10|30;
  repeat: 'daily'|'weekday'|number[];        // number[] = 星期几（0–6）
  enabled: boolean;
  voice: string;
  condition?: 'sunny'|'no_water'|'no_sun'|'no_photo'|'sedentary';
};
```

光合：

```
value = calcValue(photoScores) + sunBonus + waterBonus + walkBonus
sunBonus   = min(6, floor(sunMinutes/10)*2)
waterBonus = min(3, cups)
walkBonus  = min(3, floor(walkMinutes/10))
活动加成合计 ≤ 12/天
```

**并发计时实现：** 每会话独立 timer；切后台后以 `startTs` 差值回算时长，不丢失。

## 6. 权限与降级

| 能力 | 有权限 | 降级 |
|---|---|---|
| 日光时间/Health | 自动计入会话与结算 | 手动「开始晒太阳」计时 |
| 饮水 Health | 自动触发浇水动画 | 一键「记一杯」 |
| 计步 | 会话时段步数 + 全天折算 | 只记时长 |
| 通知 | 定时督促 | 应用内时间条 |
| 无任何权限 | 仅拍照 + 自报活动 | 仍可完整游玩 |
