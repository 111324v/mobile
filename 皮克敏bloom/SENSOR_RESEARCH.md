## 1. 晒太阳 / 光照（与植物同步）

### 1.1 手表 / 手环

| 产品 | 相关能力 | 能否给第三方读 | 建议用法 |
|---|---|---|---|
| **Apple Watch（watchOS 10+/Series 6+）** | **Health「日光时间 / Time in Daylight」**，用环境光等估算户外时长 | **可**：HealthKit `HKQuantityTypeIdentifierTimeInDaylight`（iOS 18+），读当日累计分钟与时段；SensorKit 原始 lux 仅限研究类 App | 主推：读累计/时段，驱动植物「晒太阳」。注意：开发者论坛反馈 Health 数值与 SensorKit 原始采样粒度存在差异，需真机校验 |
| Apple Watch | 环境光传感器（屏幕亮度） | 原始 lux/UV **不对三方开放** | 不依赖原始光感 |
| **Garmin（Fenix / Instinct Solar 等）** | 太阳能「Solar Intensity / 太阳能强度」、日出日落 | 导出 **FIT / Connect API**，**非实时推送** | 安卓表补充：适合「当日结算」；不适合「进行中徽章实时同步」 |
| **华为手表/手环** | 光感仅用于自动亮度；Health Kit 开放步数/心率/睡眠等 | **无日光时间/环境光类目**（已核实） | 只用于计步/睡眠，不做光照 |
| **Samsung Galaxy Watch** | 自动亮度光感、无日光时间 | 三星健康/Health Connect 有限（步数/运动/手输水分） | 次要：计步 + 水分 |
| **Amazfit / 小米手环** | 部分有光感（不开放）、户外模式 | Zepp / 米家 API 不含光照 | 仅计步 |

**结论（可写进产品）：**

1. **首选 Apple Watch「日光时间」**（最接近「人是否在晒太阳」的系统能力）  
2. **Garmin 太阳能强度 / Connect 导出**作安卓表补充  
3. **无表用户**：
   - 手机环境光 `AmbientLightSensor`（少数浏览器/原生）  
   - GPS + 天气 **UV 指数** + 在户外停留时长  
   - 用户点「开始晒太阳」计时（可与照片/定位校验）  

### 1.2 产品内映射（人 → 植物）

| 人的行为 | 检测 | 植物表现 | 光合值 |
|---|---|---|---|
| 户外晒太阳 N 分钟 | 手表日光时间 / 自计时 + 可选 GPS | **右上角太阳徽章**旋转发光，时长与人一致；植物微光粒子 | 例如 10 分钟 +2，日上限 +6 |
| 室内明亮处 | 光感 lux 较高 | 植物轻微提亮 | +1/次，日上限 +2 |
| 阴天仍出门 | GPS 在户外 + UV 低 | 风/云动画 | +1 |

## 2. 喝水（如何「知道」用户喝了）

| 方案 | 原理 | 可靠度 | 备注 |
|---|---|---|---|
| **A. 智能水杯** | HidrateSpark PRO / PRO 2（SipSense 技术，Apple Store 在售）自动记 ml，蓝牙同步并**写入 Apple Health** | 高 | 增强路径；不要求用户购买 |
| **B. Health 水分** | Apple Health「膳食水分」/ Health Connect `Hydration`；第三方喝水 App（WaterKit 等养成类竞品也写 HealthKit） | 中 | 接系统库最省事，**主路径** |
| **C. 快捷打卡** | 推送「该喝水啦」→ 一键「刚喝了一杯」+ 容量选择 | 中（自报） | 反打卡：不罚漏记，**主路径兜底** |
| **D. 时序启发式** | 固定时段提醒 + 会话检测（不强行判真假） | 低 | 仅当养成习惯 |
| **E. 音频/抬腕喝水识别** | 手机麦克风或 IMU 识别喝水动作 | 低、误报多 | **不做**硬校验 |
| **F. 摄像头识别水杯** | 拍摄水杯/水壶 | 中低 | 仅未来做「拍照水杯」软加分，不惩罚 |

**产品建议：**  
主路径 **B + C**（系统水分 + 一键打卡，有水杯则 A 自动入账）。  
植物动画只要「记录到饮水事件（≥100ml）」就播 **水壶序列帧 + 3D 水滴粒子**；不做「未喝就惩罚」。

## 4. 提醒（督促）机制

### 4.1 植物主动（文案温柔、可关闭）

| 时段 | 植物话 | 动作 |
|---|---|---|
| 08:30 | 今天要不要去窗边/阳台？我也想晒晒太阳 | 去晒太阳（开始计时） |
| 10:30 | 有点渴了，你喝过水了吗？ | 去喝水（打卡/Health） |
| 13:00 | 饭后走走吧，风从叶子边过会很舒服 | 开始散步 |
| 16:00 | 久坐啦，起来伸个懒腰～ | 深呼吸/拉伸 |
| 19:30 | 再拍一张今天的自然，喂我一顿？ | 去拍照 |
| 21:30 | 早点休息，明天还要一起晒太阳 | 早睡打卡 |

### 4.2 用户自定

- 可添加：晒太阳 / 喝水 / 散步 / 拍照 / 休息早睡  
- 时刻 + 提前量（0/10/30 分钟）+ 重复：每天 / 工作日 / 自定义星期几  
- 完整管理：添加 / 编辑 / 删除 / 单条开关  
- 权限：通知开关；系统养生类可加「健康使用时间」例外说明  
- 完整机制见 SYNC_PLAY_SPEC.md 与 UI_ARCHITECTURE.md §3.3

## 5. 技术接口（前端/端侧草案）

```text
Session        { id, kind: sun|walk|breathe|stretch|air|sunflower, startTs, endTs, minutes?, steps?, source }
InstantEvent   { id, kind: water|fruit|talk, ts, ml?, source }
Reminder       { id, kind, source: plant|user, hh, mm, advanceMin, repeat, enabled, voice, condition? }
// 完整结构见 SYNC_PLAY_SPEC.md §7 与 UI_ARCHITECTURE.md §5

// 光合追加（日上限保护）
bonusSun   = min(6, minutes/10*2)     // 例
bonusWater = min(3, cups*1)           // 例
bonusWalk  = min(3, minutes/10*1)
```

**日上限建议：** 活动加成合计 ≤ 12 光合/天，避免「只刷传感器不拍照」溢出。
