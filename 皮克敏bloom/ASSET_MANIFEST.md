## 0. 素材总决策：用 2D 还是 3D？

| 素材 | 结论 | 理由 |
|---|---|---|
| 太阳徽章 | **2D 序列帧** | 固定屏幕右上角的 HUD 元素，无视角变化，2D 贴纸感更符合皮克敏风格 |
| 浇水壶 | **3D 模型更佳**（2D 序列帧可先顶替） | 必须与 3D 花盆同处一个空间、随视角旋转；3D 水壶倾倒+粒子在场景内最自然 |
| 云朵 | **3D 模型更佳**（CSS 软云可先顶替） | 全屏 3D 场景中漂浮的云用低模 GLB（蓬松团状）立体感最好，参考图即 3D 渲染风格 |
| 植物本体 | 3D GLB | 已有 strawberry_anim.glb；其他物种待建 |
| 蝴蝶/蜜蜂等小动物 | 3D 模型（或 2D 序列帧） | 3D 可沿曲线路径飞 + 翅膀扇动，效果最佳 |
| 花盆/装饰 | 3D 模型 | 与植物同一空间 |
| UI 插画/图标/背景 | 2D | 平面元素，贴纸风 |
| 土面湿润/高光/叶摆 | 程序化（无素材） | 代码实现 |

**结论：3D 模型能明显提升水壶、云朵、动物、花盆这四类的表现力；太阳徽章和 UI 保持 2D。**

## 0.1 需要收集的 3D 模型清单（可由用户提供，格式要求统一）

| 编号 | 模型 | 用途 | 规格 |
|---|---|---|---|
| GLB-A1 | **浇水壶**（低模软萌风，带把手壶嘴） | 喝水动画：场景内倾倒 | 面数 <30k；壶嘴处留原点方便挂粒子 |
| GLB-A2 | **云朵**（蓬松团状，1-3 个变体） | 主页天空漂浮 | 面数 <5k；纯白可顶点着色 |
| GLB-A3 | 蝴蝶/蜜蜂/瓢虫（各 1） | 环境小动物 | 面数 <10k；翅膀单独分mesh便于做扇动 |
| GLB-A4 | 花盆（2-3 款变体） | 植物容器 | 面数 <20k；土面单独材质球（做湿润变色用） |
| GLB-A5 | 太阳（可选） | 若想 3D 化再给 | 面数 <5k |
| GLB-B1..B5 | 其他植物物种（向日葵/仙人掌/橘树/西瓜/松树） | 图鉴与养成主体 | 面数 <80k；**最好带生长骨骼动画**（发芽→幼苗→成熟），或至少可拆分部位 |

**统一格式要求：**
- 格式 `GLB`（glTF 2.0 二进制，贴图内嵌）
- Y 轴向上、单位为米、原点在模型**底部中心**（方便落地摆放）
- 单模型面数见上表；贴图 1024² 内
- 若带骨骼动画：动画命名 `grow`（生长）/`idle`（待机摇摆），我方接入后程序驱动

**我方接收后做的动画加工：** 水壶→倾斜倒水+粒子发射器挂壶嘴；云→漂浮路径+缓慢自转；蝴蝶→翅膀 flap + 曲线飞；花盆→土面湿润 lerp；植物→按生长进度驱动 `grow` 动画时间轴（现有草莓即是此方案）。
