## 2. 风格提炼（执行清单）

### 2.1 色彩

| 用途 | 色相 | 说明 |
|---|---|---|
| 户外天空 | `#5EC8F8 → #A8E0D0 → #7CB342` | 蓝→青→草绿竖向 |
| 选择页底 | `#FFD900 → #FEFADE` | 高饱和黄到奶油 |
| 主标题黄 | `#FFD84D` | 只用于植物名等 1–2 处 |
| 墨色字 | `#1A1A1A` / 深绿 `#0C3318` | 标题与正文 |
| 引言绿 | `#2A6010` | 斜体副标 |
| CTA 黑 | `#1A1A1A` 底 + 白字 | 胶囊 50px 圆角 |
| 强调绿 | `#4CAF50` / `#2EA44F` | 箭头圆、Tab 激活 |
| 暖橙 | `#FFB547` | 相机 FAB |
| 卡片 | `#FFFFFF` r=28 | 重投影 0 16px 48px |
| 奖励粉描边 | `#F8BBD0` | 礼盒卡细边 |

### 2.2 字体与文案

- 英文大标题：**很粗、字距小**（Sunflower / Choose Your Plant）
- 状态副标：**大字距全大写**（RADIANT）
- 引言：**斜体 + 居中**
- 数字奖励：大号 + 红色/橙色（68,980）
- 倒计时：`14 日 16 小时` 粗数字 + 细单位

### 2.3 图形语言

| 元素 | 做法 |
|---|---|
| 云 | **棋盘格半调抖动**下缘（不是高斯模糊） |
| 地面 | 像素草丛剪影 + 小花点缀 |
| 蝴蝶 | 简化像素蝶，少量飘飞 |
| Icon | 贴纸/像素感，**禁止系统 emoji 当图标** |
| 礼盒/芽 | 3D 贴纸感红蝴蝶结礼盒 + 小芽 |
| 明信片 | 横卡 + 红字地点 + 大数字 |

### 2.4 布局

- 顶部：植物名（黄）+ 状态（小字距）或进度标题
- 中上：对话气泡（圆角、尖角）
- 中部：**角色/植物主体**（像素场景中的向日葵 = 我们的 3D 植物）
- 右下：**橙色圆形拍照 FAB**
- 底部：简洁 Tab 或圆点分页
- 选择页：中卡放大、左右卡露出 80% 并倾斜

### 2.5 动效

- 云缓慢平移
- 蝴蝶曲线路径
- 植物轻微呼吸
- 按钮 scale 0.95
- 进度/数字使用轻浮出，不用强弹跳

### 2.6 同步玩法动效风格规范

| 元素 | 美术语言 |
|---|---|
| 太阳徽章（S-01 序列帧） | 贴纸感厚白描边圆太阳，暖橙渐变 #FFF6C8→#FFB547；旋转用整帧切换（8 帧），不用 CSS 渐变模拟；发光靠外圈光晕层，不做刺眼辉光 |
| 水壶（S-03 序列帧） | 薄荷绿/奶油壶身，粗描边贴纸风；出水线为连续弧线非断点；12 帧 0.8s，节奏前缓后急 |
| 水滴粒子 | 3D 内圆点粒（#7EC8FF），落地小水花 2 帧即回收，数量 ≤40 保持轻量 |
| 土面湿润 | 仅颜色加深（无贴图更换），2s 线性恢复——克制的「真的喝到了」反馈 |
| 植株高光 | emissive 扫过 1.2s，同时「+N 光合」轻浮出（沿用数字轻浮出规则） |
| 施肥（S-09） | 营养颗粒 + 果香泡泡，沙沙音效，节奏与浇水一致 |
| 提示音 | 短、软、拟物（水滴声/风铃声），音量默认 40%，不用系统提示音 |
| 总原则 | 动画是**奖励反馈**不是干扰：单次 ≤1.5s，可被下一次同类事件打断重播，绝不循环超过 2 次 |

## 4. 一句话风格宣言

**「像素自然舞台 + 贴纸 UI + 礼物收集」**：  
户外是 dither 像素风景，交互是圆角贴纸与黑胶囊按钮，激励是礼盒/明信片/倒计时，不用任何系统 emoji 图标。
