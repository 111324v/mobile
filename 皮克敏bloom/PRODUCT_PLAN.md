## 1. 一句话

用户拍照 + **人植同步活动**（晒太阳 / 喝水 / 散步…）→ 光合值 → 3D 植物连续生长 →  
成熟后领取 **明信片 / 时令水果**，并合成「植物 × 环境照片」纪念卡。

---

## 2. 核心循环

```
        ┌──────────── 日常 ────────────┐
        │  拍照(1~3次)  +  活动打卡/传感器 │
        └──────────────┬───────────────┘
                       ▼
              四要素 / 活动事件
                       ▼
        光合值 = 拍照分 + 活动加成(日上限)
                       ▼
            3D 植物生长进度 0–100%
                       ▼
         成熟 → 明信片/水果 + 图鉴解锁
```

### 2.1 拍照光合（主路径）

```
单次 = (光×c0 + 水×c1 + 气×c2 + 境×c3) × 均衡系数(0.6–1.3)
四要素 0–3；累计 300 成熟
节奏：约 15 天 × 3 张/天 ≈ 50 张
```

### 2.2 活动加成（次路径）

| 活动 | 检测 | 加成（示例） | 日上限 |
|---|---|---|---|
| 户外晒太阳 | 手表日光时间 / 自计时 + 可选 GPS-UV | 10 分钟 +2 | +6 |
| 喝水 | Health 水分 / 一键 / 智能杯 | 一杯 +1 | +3 |
| 散步 | 步数/计时 | 10 分钟 +1 | +3 |
| 深呼吸 / 早睡 | 引导 / 打卡 | 均衡系数软加成 | — |

**设计约束：** 活动加成合计 ≤12/天，保证「拍照养成」仍是主心骨；漏打卡不惩罚（反打卡）。

## 4. 提醒督促

### 4.1 植物主动（默认开，可关，条件触发）

固定时刻表（08:30 晒太阳 / 10:30 喝水 / 13:00 散步 / 16:00 久坐 / 19:30 拍照 / 21:30 早睡）+ 条件触发（今晨无饮水、今日未晒太阳、紫外线高等才提醒）。文案第一人称、不说教；点击直达对应动作。防打扰：单日 ≤4 条，静音时段 22:00–08:00，可让植物安静一天。

### 4.2 用户自定义

- 类型：晒太阳 / 喝水 / 散步 / 拍照 / 休息早睡
- 时间：指定时刻 + 提前量（0/10/30 分钟）+ 重复（每天/工作日/自定义星期几）
- 通知文案可选「植物口吻」或自定义文本
- 完整管理：添加 / 编辑 / 删除 / 单条开关
- 交互与数据结构见 `UI_ARCHITECTURE.md` 与 `SYNC_PLAY_SPEC.md` §7
