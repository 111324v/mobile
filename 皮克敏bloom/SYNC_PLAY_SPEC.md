## 1. 互动模式总览

所有互动按「用户参与方式」分为四类：

| 类型 | 特征 | 包含活动 |
|---|---|---|
| **会话型** | 有明确的「开始 / 结束」，进行中实时计时，可多个同时进行 | 晒太阳、散步、深呼吸、拉伸起身、开窗通风、追光任务 |
| **瞬时型** | 一键记录，立即播放反馈动画，无会话 | 喝水、吃水果（施肥）、对植物说话 |
| **自动同步型** | 无需操作，App 自动读取数据/环境并触发反馈 | 日光时间（手表）、全天步数、睡眠早睡、雨天检测、到访新地点 |
| **周期/长线型** | 跨天的成就与社交 | 连续 7 天达标、夜间护眠、好友互相浇水 |

### 1.1 并发模型（核心规则）

- **会话型活动彼此独立，可同时进行**：例如先点「散步」开始，再点「晒太阳」开始——两个计时器并行运行，互不影响；出门散步本身往往就在晒太阳，这是符合直觉的设计。
- 同时进行的会话数量上限 **3 个**；喝水等瞬时事件不占会话数。
- 每个进行中的活动在主页快捷动作条上有独立状态（卡片高亮 + 计时文字），点击进行中的卡片 → 打开该会话卡片（可结束）；结束只结束当前这一个，其他会话继续。
- 各会话**独立结算**：各自播自己的动画、各自加各自的光合值。
- 单活动每日结算有上限（见 §5），同一天反复开始结束只累计到上限为止。

### 1.2 通用入口（每个活动都有的触发方式）

| 入口 | 说明 |
|---|---|
| 主页快捷动作条 | 晒太阳 / 喝水 / 散步 三个常驻卡片，一击直达 |
| 「同步」页 | 全部活动的对照卡片 + 进行中会话详情 |
| 提醒通知 | 点击植物提醒 → 深链直达对应活动的开始按钮 |
| 自动同步 | 授权后无需任何点击（日光时间 / 睡眠 / 步数 / 天气） |

## 2. 会话型活动（详细流程）

### 2.0 会话型通用流程

```
入口点击「开始」
  → 卡片变为「进行中」高亮，显示实时计时 mm:ss
  → 展开会话卡片（大计时器 + 结束按钮 + 实时数据）
  → （期间可再开其他会话型活动，见 §1.1）
  → 用户点「结束」（或达到自动条件）
  → 结算动画 + 光合值入账 + 活动写入日记
```

### 2.1 晒太阳

| 环节 | 内容 |
|---|---|
| 入口 | 主页快捷条「晒太阳」卡片 / 同步页对照卡 / 植物提醒「今天太阳很好，带我一起去阳台吧？」 |
| 开始 | 点击 → 会话卡片展开，计时开始；**右上角出现太阳徽章**（8 帧序列帧旋转 + 外圈进度弧 + 实时 mm:ss） |
| 进行中 | 徽章与计时 1:1 同步；期间可同时开散步/深呼吸等其他会话；卡片文案「晒太阳进行中 · 与右上角徽章同步」 |
| 结束 | ① 手动点「结束并结算」② 自动模式（已授权手表日光时间）按手表记录的分钟自动入账，无需手动开始结束 |
| 结果 | 植株 emissive 高光扫过 1.2s + 「+N 光合」轻浮出 + 叮声；日记记录「晒太阳 N 分钟」 |
| 数据 | `SunSession{ startTs, endTs, minutes, source: 手表日光时间/手动计时/GPS+UV }` |
| 光合 | 10 分钟 = +2，日上限 +6 |

### 2.2 散步

| 环节 | 内容 |
|---|---|
| 入口 | 主页快捷条「散步」卡片 / 同步页 / 植物提醒「饭后走走吧」 |
| 开始 | 点击 → 会话卡片展开（大计时器 + 「结束」按钮）；已授权步数时显示实时步数 |
| 进行中 | 计时 + 计步并行显示；**可与晒太阳同时进行**（卡片两条高亮并存）；叶片微风摆动画常驻轻效果 |
| 结束 | 用户点「结束」→ 自动抓取本时段数据：时长总是记录；步数在授权时按「开始~结束时间段」从系统健康库查询该时段新增步数 |
| 结果 | 叶片 z 向摆动 2 次 + 气流线 + 「+N 光合」；日记记录「散步 N 分钟 / M 步」 |
| 数据 | `WalkSession{ startTs, endTs, minutes, steps?, source: 系统计步/手动 }` |
| 光合 | 10 分钟 = +1，日上限 +3 |

### 2.3 深呼吸

| 环节 | 内容 |
|---|---|
| 入口 | 同步页对照卡「深呼吸」/ 提醒「起来动一动」 |
| 开始 | 进入引导页：气泡环随呼吸节奏胀缩，用户跟随吸气-呼气 3 轮 |
| 进行中 | 植株以同节奏轻微舒展（缩放呼吸）；气泡环在屏幕中央引导 |
| 结束 | 3 轮完成自动结束（也可中途退出） |
| 结果 | 植株舒展动画 + 均衡系数 +0.05（当日有效） |
| 并发 | 可与晒太阳/散步同时（引导页返回主页后会话仍在跑） |

### 2.4 拉伸起身（久坐提醒联动）

| 环节 | 内容 |
|---|---|
| 入口 | 手表/手机久坐提醒推送 → 点击直达；或同步页手动开始 |
| 流程 | 引导 4 个拉伸动作各 30 秒（图示 + 倒计时）；植株做「伸懒腰」弹性形变动画 |
| 结束 | 完成自动结算：贴纸奖励（收集图鉴用）+ 植物开心微动 |
| 光合 | 无光合，给贴纸（避免刷分） |

### 2.5 开窗通风

| 环节 | 内容 |
|---|---|
| 入口 | 同步页「开窗通风」卡 |
| 开始 | 点击开始 → 5 分钟倒计时建议（可提前结束，≥2 分钟有效） |
| 进行中 | 叶片连续轻摆 + 气流线常驻 |
| 结果 | 气要素 +1（计入当日四要素） |

### 2.6 向日葵追光任务

| 环节 | 内容 |
|---|---|
| 入口 | 同步页趣味任务卡（物种为向日葵时解锁） |
| 流程 | 引导用户面朝太阳方向站定 → 用手机指南针检测朝向，保持 1 分钟 |
| 进行中 | 3D 花盘实时转向用户面对的方向（Follow 动画） |
| 结果 | 完成给趣味贴纸「向日葵的注视」；无光合 |

## 3. 瞬时型活动

### 3.1 喝水

| 环节 | 内容 |
|---|---|
| 入口 | 主页快捷条「喝水」卡片 / 同步页「记一杯」/ 提醒「我有点渴了」/ 智能水杯蓝牙自动 |
| 触发 | 点一下 = 记录一杯 250ml（长按可自选容量 150/300/500ml） |
| 结果 | **立即播放浇水动画**：12 帧水壶序列在花盆上方倾倒 + 3D 水滴粒子落土 + 土面颜色加深 2s 后恢复 + 水滴音效；快捷条显示今日累计 ml |
| 数据 | `HydrationEvt{ ts, ml, source: 手动/系统健康库/智能水杯 }`；系统健康库/水杯来源每次 ≥100ml 自动触发同样动画 |
| 光合 | 1 杯 = +1，日上限 +3 |
| 特点 | 无会话、可随时点、可与其他会话并行 |

### 3.2 吃水果（施肥彩蛋）

| 环节 | 内容 |
|---|---|
| 入口 | 同步页「今天吃水果了吗」卡 → 一键打卡 |
| 结果 | 营养颗粒撒到土面的施肥动画 + 果香泡泡；水/境要素 +1 |
| 说明 | 不做图像校验、不惩罚；每日 1 次 |

### 3.3 对植物说话

| 环节 | 内容 |
|---|---|
| 入口 | 主页点植物 / 对话气泡 |
| 流程 | 输入或语音说一句话 → 植物对话气泡回应（预设文案库）+ 植株开心微动 |
| 结果 | 无数值奖励，纯情感互动；特殊节日有彩蛋回复 |

## 4. 自动同步型（无需操作）

| 活动 | 触发条件 | 用户看到 | 结果 |
|---|---|---|---|
| 日光时间（手表） | 授权后，手表记录到户外光照 | 打开 App 时若有新日光记录：植物头顶小太阳 + 「你今天在户外晒了 N 分钟」提示条 | 按分钟折算光合（同 2.1 上限），可回看 |
| 全天步数 | 授权计步 | 当日累计步数折算散步分钟（10 分钟起算） | 与手动散步会话共享日上限 |
| 早睡 | 手表睡眠数据 / 22:30–次日 6:00 间无手机使用并打卡 | 第二天早上打开：夜间叶片合拢回放 + 月亮星星小动画 + 「昨晚我们睡得很好」 | 均衡系数加成 |
| 雨天听雨 | 定位当天有降雨 | 主页下雨氛围（雨滴落土、水花、玻璃水雾滤镜） | 水要素 +1 |
| 到访新地点 | GPS 到达公园/海边/山地等预设类型 | 弹出「发现新场景」卡，解锁对应生物群系贴纸 | 境要素加成 + 图鉴 |

## 5. 周期 / 长线型

| 活动 | 机制 | 奖励 |
|---|---|---|
| 连续 7 天达标 | 当日「拍照+活动」合计 ≥ 目标即算达标，连续计数 | 第 7 天：花开加速粒子 + 均衡系数 +0.1（持续 3 天） |
| 夜间护眠 | 22:00 后不打开 App（可打卡豁免） | 次晨植物「睡饱」状态，光合 +1 |
| 好友互相浇水 | 弱社交：好友可给你的植物浇一次水（每日 1 次） | 收到浇水播同款浇水动画 + 情感留言 |

## 6. 光合值汇总与上限

```
拍照光合（主路径）   ：四要素评分 × 均衡系数，累计 300 成熟
活动加成（次路径）   ：晒太阳 ≤6 / 喝水 ≤3 / 散步 ≤3 / 通风等 ≤2
活动加成合计上限     ：≤ 12 /天
反打卡原则           ：漏打卡不惩罚；只活动不拍照不能成熟（至少 20 次拍照）
```

## 7. 数据结构（最终版）

```ts
type Session = {           // 会话型活动通用
  id: string;
  kind: 'sun'|'walk'|'breathe'|'stretch'|'air'|'sunflower';
  startTs: number; endTs?: number;
  minutes?: number; steps?: number;          // 结束时写入
  source: 'auto'|'manual';                   // 自动同步 / 手动会话
};
type InstantEvent = {      // 瞬时型
  id: string;
  kind: 'water'|'fruit'|'talk';
  ts: number; ml?: number;
  source: 'manual'|'health'|'bottle';
};
type Reminder = {
  id: string;
  kind: 'sun'|'water'|'walk'|'photo'|'rest';
  source: 'plant'|'user';                    // 植物主动 / 用户自定义
  hh: number; mm: number;
  advanceMin: 0|10|30;                       // 提前量
  repeat: 'daily'|'weekday'|number[];        // number[] = 星期几 0–6
  enabled: boolean;
  voice: string;                             // 通知文案（植物口吻）
  condition?: 'sunny'|'no_water'|'no_sun'|'no_photo'|'sedentary';
};
```

## 8. 实现要点

- **动画分层**：太阳徽章 = 2D 序列帧（HUD 层）；浇水 = 2D 序列帧（屏幕投影锚定花盆）+ 3D 水滴粒子 + 土面材质变化；高光/叶摆 = 3D 程序化。素材规格见 ASSET_MANIFEST.md，数据来源见 SENSOR_RESEARCH.md。
- **并发计时**：每会话独立 timer；切后台用 `startTs` 差值回算，不丢时长。
- **权限降级**：无任何传感器权限时，所有活动退化为手动开始/结束 + 打卡，完整可玩。
