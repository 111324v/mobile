# 光合作用 30 秒 16:9 最终方案（已补全素材逻辑）

## 一、目标
生成一支 **16:9 横版、30 秒、专业产品宣传质感、像素治愈风** 的宣传片。

### 总要求
- **不要新增任何画面文字文案**，包括中文、英文、数字都不要额外添加。
- **UI 页面素材本身已有的文字可以保留**，不视为新增文案。
- **不要使用粒子、光晕、能量光点、爆闪等明显 AI 味特效**。
- **阴影要轻、柔、浅**，不要黑厚重。
- **最终成片是 16:9**，但所有 UI 页面必须严格按它们各自的原始像素比例呈现，**可以裁切，不可以拉伸变形**。
- **完整 UI 页面必须放入 iPhone 15 Pro 手机样机中**。
- **拆分小卡片、图标、缩略图等只作为纯浮层卡片出现，不要手机壳，不要刘海，不要金属边框**。
- **右下角水印如有需要，通过裁切 / 遮挡处理，不要拉伸修补**。
- 画面动效以**镜头推进、页面位移、软遮罩、轻抬升、轻景深、页面状态切换**为主，整体像真实产品广告，不要特效秀。

## 二、素材分层与点击逻辑

### 1）全局背景层
- **`背景.png`** 是整支 16:9 视频的**全局底层背景**。

- 全片都应基于它建立空间关系，只有在完整手机页面铺满时才通过边缘、留白、阴影露出背景。

### 2）完整手机 UI 页面层
这些素材必须作为**完整 App 页面**出现，并统一放入 iPhone 15 Pro 样机中：
- `启动页.png`
- `选择植物.png`
- `拍摄页-未打开摄像头.png`
- `拍摄页-未点击拍摄按钮.png`
- `拍摄页-点击拍摄按钮后.png`
- `主页-早期.png`

- `图库.png`

### 3）拆分小卡片层
这些素材只作为纯浮层小卡片出现，不要手机壳：
- `向日葵.png`
- `仙人掌 (1).png`
- `松树 (1).png`

### 4）状态动画层
这 4 个 MP4 要真正用进镜头里，作为叙事节点，不要只当装饰：
- `动画-向日葵-生长.mp4`
- `动画-向日葵-夜晚.mp4`
- `动画-向日葵-雨天.mp4`

### 5）自然环境素材
- `自然环境.png`：用于拍摄段落中，手机对准的自然环境目标画面。

### 6）功能盘数据 icon
- `image(1).png` 中的柱状图图标，是 **`主页面-功能盘.png` 上的数据 icon**。
- 它不是装饰图形，而是一个可点击入口。
- 正确逻辑是：
  - `主页面-植物.png`
  - 点击右下角功能盘按钮 → `主页面-功能盘.png`
  - 点击功能盘上的数据 icon（即 `image(1).png` 的柱状图图标）→ `主页面-展开.png`
- `主页面-展开.png` 不是独立无关页面，而是主页面右侧 / 数据区域的展开面板状态。

## 三、品牌事实
- 产品名：`Photosynthesis / 光合作用`
- 标语：`Every step into nature counts.`
- 核心主张：通过拍摄自然的日常行为陪伴植物成长，记录用户走向自然的瞬间。
- 视觉风格：像素治愈风、专业产品宣传质感、干净背景、轻投影、空间化 UI。
- 交互语言：白色像素光标、悬停抬升、点击反馈、真实相机震动、扫描框识别、页面状态变化。

## 四、素材点击关系总说明

### 主路径
**背景.png → 启动页.png → 选择植物.png → 主页-早期.png → 主页面-植物.png → 主页面-功能盘.png → 主页面-展开.png → 拍摄页流程 → 图库.png / 我的.png → 品牌收尾**

### 具体逻辑
1. **`背景.png`** 作为全局 16:9 底层背景贯穿全片。
2. **`启动页.png`** 作为品牌入口出现。
3. 进入 **`选择植物.png`**，点击植物小卡片进入主页早期状态。
4. `主页-早期.png` 经过成长过渡，变为 `主页面-植物.png`。
5. 在 `主页面-植物.png` 中点击右下角功能盘按钮，弹出 `主页面-功能盘.png`。
6. 在 `主页面-功能盘.png` 中点击数据 icon（即用户提供的柱状图截图）后，展开为 `主页面-展开.png`。
7. 从 `主页面-功能盘.png` 进入拍摄流程：
   - `拍摄页-未打开摄像头.png`
   - `拍摄页-未点击拍摄按钮.png`
   - `拍摄页-点击拍摄按钮后.png`
8. 拍摄后进入植物状态延展：
   - `动画-向日葵-雨天.mp4`
   - `动画-向日葵-夜晚.mp4`
   - `动画-向日葵-茁壮态.mp4`
9. 最后进入档案和个人中心：
   - `图库.png`
   - `我的.png`
10. 全片收束回品牌 Logo 与标语。

## 五、详细镜头描述

### 0–3 秒：封面入口
- 浅色干净背景上，Photosynthesis Logo、中文名、标语自然淡入。
- 白色像素光标从边缘滑入，轻点 Logo。
- 镜头沿 Z 轴推进，穿过 Logo 中心，进入产品空间。
- 这一段保持安静、干净、克制，不加任何额外文字。

### 3–6.5 秒：选择植物
- `选择植物.png` 作为完整手机 UI 页面进入画面，必须放入 iPhone 15 Pro 样机中。
- 页面内部浮出三张独立小卡片：
  - `向日葵.png`
  - `仙人掌 (1).png`
  - `松树 (1).png`
- 这三张卡片都必须是纯浮层卡片，不要手机壳，不要刘海，不要变成另一台手机。
- 光标悬停向日葵卡片，卡片轻微抬升，阴影略变深但保持柔和。
- 点击后，向日葵卡片产生轻微缩放反馈。
- 镜头推入向日葵卡片中心，用卡片圆角做软遮罩过渡进入下一段。

### 6.5–10 秒：出门拍自然
这一段需要加入**一双手拿出手机**的镜头。

- 一双手把手机自然拿入画面，对准 `自然环境.png` 所对应的自然环境。
- 先显示 `拍摄页-未打开摄像头.png`：手机屏幕是黑色取景界面，仍然位于手机样机内部。
- 再切到 `拍摄页-未点击拍摄按钮.png`：摄像头打开后，屏幕显示自然环境实景。
- 像素鼠标点击拍摄按钮后，只出现轻微真实相机震动反馈。
- 使用 UI 页面里**原本就有的扫描框**，让它开始扫描识别；扫描线平稳下扫，轻微亮起即可，不要额外叠加光晕或粒子。
- 然后自然过渡到 `拍摄页-点击拍摄按钮后.png`，展示这次拍摄得到的四要素和光合值结果。

### 10–14 秒：拍摄结果 / 识别反馈
- 切到 `拍摄页-点击拍摄按钮后.png`。
- 保持 UI 自带的结果呈现方式，不额外加说明文案。
- 不做数字爆闪，不做粒子回收，不做光点飞散。
- 结果出现要像产品反馈，而不是特效演示。

### 14–17.5 秒：植物成长
- 从 `主页-早期.png` 的幼苗状态进入。
- 使用 `动画-向日葵-生长.mp4` 作为中间过渡，让幼苗自然长成成熟状态。
- 最后平滑落到 `主页面-植物.png` 的成熟状态。
- 这个成长过程要像像素逐格长开，不要粒子拼接，不要大范围发光。

### 17.5–21.5 秒：状态延展
- 这一段使用剩余三个向日葵 MP4，但要各自承担明确的状态叙事，不要堆叠成素材拼贴。
- 使用逻辑如下：
  - `动画-向日葵-雨天.mp4`：对应雨天状态，气氛安静，不低落。
  - `动画-向日葵-夜晚.mp4`：对应夜晚状态，更慢、更静。
  - `动画-向日葵-茁壮态.mp4`：对应成熟、稳定、强壮的收束状态。
- 这三段状态变化要像从主页面中自然浮出的状态段落，不要作为独立装饰层。
- 不加任何额外文字。

### 21.5–25.5 秒：功能盘与数据展开、档案记录
- 在 `主页面-植物.png` 中点击右下角功能盘按钮，进入 `主页面-功能盘.png`。
- 在 `主页面-功能盘.png` 中点击**数据 icon**（即 `image(1).png` 的柱状图图标）后，展开为 `主页面-展开.png`。
- `主页面-展开.png` 是主页面的数据面板展开状态，不是独立无关页面。
- 之后 `图库.png` 和 `我的.png` 作为完整手机 UI 页面前后错落滑入。
- 页面内的日历、缩略图、记录内容按原 UI 自身方式点亮。
- 只保留 UI 原本的文字，不要再加新的说明标签。
- 画面继续保持克制、轻微位移、轻推镜。

### 25.5–30 秒：品牌收束
- 所有 UI 页面逐步退远、缩小、淡出，回到干净浅色背景。
- Photosynthesis Logo、中文名、标语再次回到中心。
- 光标最后轻点 Logo，画面稳定收尾。
- 不做粒子聚合，不做光晕，不做炫技式品牌爆闪。
